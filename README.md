# Percorsi nella letteratura italiana
Sito web dimostrativo dedicato alla letteratura italiana, in particolare alcuni autori e temi del Romanticismo.

# Descrizione
Il sito è stato realizzato come ambiente dimostrativo per sperimentare l'integrazione di un Accessibility Layer, un prototipo di personalizzazione dell'accessibilità cognitiva sviluppato nell'ambito di un progetto di tesi presso l'Alma Mater Studiorum di Bologna.

# Accessibility Layer
Il sito integra un componente che mette a disposizioni sturmenti di personalizzazione della consultazione dei contenuti, tra cui:
- modifica del carattere tipografico e della dimensione del testo
- regolazione dell'interlinea e della spaziatura
- modalità di contrasto
- glossario interattivo
- riassunti personalizzabili
- indice dei contenuti
- memorizzazione delle preferenze

Il componente è documentato separatamente nel repository dedicato:
Accessibility Layer- Repository

# Tecnologie
Il progetto utilizza HTML, CSS e JavaScript.

# Contesto accademico
Il sito costituisce l'ambiente di sperimentaione del prototipo sviluppato nell'ambito di una tesi di laurea presso l'Alma Mater Studiorum di Bologna.
